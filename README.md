# Pulso Cívico

Módulo de participação cívica gamificada do Observatório Eleitoral.

> Estado inicial: fundação documental em construção. Nenhum resultado real de pesquisa é exibido nesta etapa.

## Objetivo

Permitir participação voluntária em consultas internas, com resultados agregados, transparência metodológica e gamificação educativa sem direcionamento político.

## Escopo do MVP

- PWA responsiva.
- Perguntas de participação voluntária.
- Separação explícita entre consulta interna, pesquisas eleitorais profissionais e apuração oficial.
- Proveniência, privacidade, moderação e prevenção de abuso como requisitos de produto.

Consulte a documentação em `docs/` após a PR de fundação.
