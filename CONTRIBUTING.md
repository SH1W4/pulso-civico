# Contribuindo

Obrigado por contribuir com o Pulso Cívico.

## Fluxo de trabalho

1. Abra ou vincule uma Issue antes de mudanças relevantes.
2. Crie uma branch curta a partir de `main`: `feat/`, `fix/`, `docs/` ou `chore/`.
3. Faça commits pequenos e descritivos.
4. Abra uma Pull Request para `main`; não faça push direto em `main` para mudanças de produto.
5. Descreva motivação, escopo, testes e riscos.
6. Aguarde revisão e verificações antes do merge.

## Regras de produto e dados

- Nunca invente ou simule dados reais sem identificá-los como demonstração.
- Nunca apresente uma consulta voluntária aberta como pesquisa probabilística representativa.
- Não atribua pontos, níveis ou recompensas a preferências por candidatos, partidos ou posições políticas.
- Minimize dados pessoais e não inclua segredos, tokens ou informações sensíveis em commits.
- Toda fonte externa deve ser identificada e sua licença/termos de uso avaliados.
- Mudanças de coleta, retenção, consentimento ou publicação exigem revisão explícita.

## Commits

Use mensagens objetivas, por exemplo: `feat: add anonymous poll flow`, `fix: validate poll submission`, `docs: clarify sampling limitations`.

## Critérios mínimos da PR

- [ ] Escopo e comportamento descritos.
- [ ] Testes executados ou motivo da ausência documentado.
- [ ] Acessibilidade e experiência mobile consideradas.
- [ ] Privacidade e abuso avaliados quando aplicável.
- [ ] Nenhuma métrica de demonstração apresentada como dado real.
