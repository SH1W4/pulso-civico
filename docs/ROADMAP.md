# Roadmap do MVP

## M0 — Fundação documental (esta PR)

- [x] Escopo do produto.
- [x] Arquitetura inicial.
- [x] Governança de dados e privacidade.
- [x] Fluxo de contribuição e template de PR.
- [ ] Revisão humana e aprovação da PR.

## M1 — Interface navegável

- [ ] Aplicação Next.js com TypeScript.
- [ ] Layout responsivo e acessível.
- [ ] Página de introdução e consulta demonstrativa identificada como tal.
- [ ] Formulário com validação no cliente e no servidor.
- [ ] Estados vazios, erros e conclusão.
- [ ] Sem persistência real até que a política de privacidade esteja aprovada.

## M2 — Serviço de consultas

- [ ] Modelo versionado de consulta e opções.
- [ ] API de submissão com validação.
- [ ] Estratégia proporcional contra duplicação e automação.
- [ ] Persistência e retenção definidas.
- [ ] Consentimento e aviso de privacidade aprovados.

## M3 — Resultados agregados

- [ ] Agregação reproduzível e testada.
- [ ] Limiar mínimo de publicação.
- [ ] Exibição de contagens, distribuição e última atualização.
- [ ] Aviso de amostra voluntária em destaque.
- [ ] Nenhuma margem de erro probabilística indevida.

## M4 — Gamificação educativa

- [ ] Pontos por conclusão, nunca pela opção escolhida.
- [ ] Conquistas educativas e acessíveis.
- [ ] Proteção contra farming e submissões repetidas.
- [ ] Testes para confirmar neutralidade das recompensas.

## M5 — Preparação para lançamento

- [ ] Testes de segurança e acessibilidade.
- [ ] Política de privacidade, termos e contato operacional publicados.
- [ ] Observabilidade e resposta a incidentes.
- [ ] Revisão de conformidade e validação do responsável pelo produto.

## Critérios de aceite do MVP

O MVP está pronto para piloto quando uma pessoa consegue abrir um link em celular, compreender a natureza voluntária da consulta, responder sem fornecer dados pessoais desnecessários, receber confirmação e visualizar apenas agregados corretamente rotulados. Os testes devem provar que respostas não são recompensadas pelo conteúdo político e que dados de demonstração não se misturam com produção.
